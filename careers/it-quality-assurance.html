IT Quality Assurance

JOB DESCRIPTION

We are seeking a QA Engineer with strong experience in manual testing, API validation, and data verification for web-based applications and reporting platforms. In this role, you will take ownership of product quality, collaborate closely with Product Owners and Engineers, and ensure the reliability, accuracy, and stability of our systems.

TEST PLANNING & EXECUTION

  • Analyze business requirements, user stories, UX flows, and technical designs to identify test requirements, risks, and testing strategies.
  • Develop detailed test cases, test scenarios, test checklists, and test reports with comprehensive coverage.
  • Execute functional, regression, integration, system, and exploratory testing across web applications and APIs.
  • Validate end-to-end workflows across frontend, backend services, databases, and third-party integrations.
  • Verify data accuracy and consistency across APIs, databases, and user interfaces.
  • Perform API testing using Postman, including collections, environments, assertions, and scripts.
  • Validate reporting dashboards, analytics systems, scheduled jobs, and data processing workflows.

QUALITY OWNERSHIP & COLLABORATION

  • Independently assess product quality and proactively identify potential risks during development.
  • Clearly document, report, and communicate test results, defects, and quality concerns to stakeholders.
  • Work closely with Product Owners, Business Analysts, and Developers to clarify requirements, estimate testing efforts, and define acceptance criteria.
  • Own the defect lifecycle, including reporting, verification, retesting, and closure.
  • Participate actively in Agile/Scrum ceremonies and release planning activities.
  • Contribute ideas and improvements to testing processes, product quality, system stability, and user experience.

RELEASE & PRODUCTION VALIDATION

  • Participate in release validation and production smoke testing after deployments.
  • Support incident investigation by validating fixes and reproducing production issues.
  • Monitor system behavior after releases and proactively identify potential quality risks.

YOUR SKILLS AND EXPERIENCE

REQUIRED

  • 2–5 years of experience in software testing for web applications, SaaS platforms, reporting systems, or data-intensive applications.
  • Strong experience in manual testing and exploratory testing.
  • Strong experience creating test cases, test scenarios, test checklists, and test reports.
  • Hands-on experience with API testing using Postman.
  • Solid SQL skills for data validation and troubleshooting.
  • Experience validating data across APIs, databases, and UI layers.
  • Familiarity with integration testing and end-to-end business workflows.
  • Experience using defect tracking and project management tools (Notion, Jira, or equivalent).
  • Ability to analyze browser console logs, network traffic, API responses, and application logs.
  • Strong analytical thinking and problem-solving skills.
  • Strong communication and collaboration skills.
  • Experience working in Agile/Scrum environments.

PREFERRED QUALIFICATIONS

  • Experience testing analytics, reporting, or dashboard platforms.
  • Experience working with third-party API integrations.
  • Experience testing ETL processes, batch jobs, or data pipelines.
  • Familiarity with CI/CD workflows and release processes.
  • Basic understanding of cloud environments and system monitoring.
  • Experience or interest in test automation using Playwright, Selenium, or similar tools.
  • English communication skills are a plus.

NICE-TO-HAVE

  • Experience in AdTech, MarTech, Data Platforms, E-commerce, or FinTech.
  • Experience validating large datasets and business-critical reports.
  • Familiarity with monitoring and alerting systems.
  • Experience using AI tools to improve testing productivity and test coverage.
  • Strong product mindset with a passion for delivering high-quality software.
